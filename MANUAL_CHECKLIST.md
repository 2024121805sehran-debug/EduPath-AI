# Manual Testing Checklist for EduPath AI

Use this checklist to test and verify all functionality in **EduPath AI**.

---

## 1. Authentication & Session Persistence
- [ ] **Sign Up Flow**:
  - [ ] Navigate to `/auth` and select the **Sign Up** tab.
  - [ ] Fill out full name, email address, password, select course/year/semester, and submit.
  - [ ] Verify instant login and redirection to `/dashboard`.
- [ ] **Login Flow**:
  - [ ] Log out via `/profile` or top navbar.
  - [ ] Navigate to `/auth`, enter existing email & password, click **Sign In**.
  - [ ] Verify successful authentication.
- [ ] **Session Refresh**:
  - [ ] Refresh the browser page (`F5`) while logged in.
  - [ ] Verify you remain logged in without being redirected to `/auth`.
- [ ] **Demo Mode Bypass**:
  - [ ] Click **Explore Demo Mode (Offline)** on the login screen.
  - [ ] Verify seamless access to the app without backend credentials.

---

## 2. Dynamic Curriculum & Course Switching
- [ ] **Browse Catalog**:
  - [ ] Navigate to `/subjects`.
  - [ ] Verify subjects, units, and topic counts for the selected course & semester.
- [ ] **Switch Year / Semester**:
  - [ ] Navigate to `/profile` or click **Switch Course / Semester** on Dashboard.
  - [ ] Change year or semester and save.
  - [ ] Confirm subjects update dynamically across Dashboard, Subjects page, and Progress Analysis.

---

## 3. Realtime Learning & Progress Syncing
- [ ] **Topic Completion**:
  - [ ] Open a subject topic (e.g. `/subjects/cs201/topics/cs201-t1`).
  - [ ] Scroll down and click **Mark Topic as Completed (+50 XP)**.
  - [ ] Confirm completion status changes and progress bar updates.
- [ ] **Supabase Sync**:
  - [ ] Check Supabase Dashboard -> Table Editor -> `user_topic_progress`.
  - [ ] Verify a record is created with `status = 'completed'` and `user_id` matching your logged in user.

---

## 4. Quizzes & Assessment Performance
- [ ] **Take Quiz**:
  - [ ] Navigate to a quiz (e.g. `/quizzes/q-cs201`).
  - [ ] Answer all questions and submit.
  - [ ] Verify immediate score calculation, pass/fail status, and XP award toast notification.
- [ ] **Quiz Records**:
  - [ ] Check Supabase Dashboard -> `user_quiz_attempts`.
  - [ ] Verify score, percentage, and passed boolean are saved.

---

## 5. Coding Practice System
- [ ] **Problem List**:
  - [ ] Navigate to `/coding` to view 15+ coding problems filtered by category (Arrays, Strings, Searching, Sorting, Linked Lists, Trees, Graphs, Dynamic Programming).
- [ ] **Code Editor & Execution**:
  - [ ] Select a problem (e.g. "Two Sum").
  - [ ] Toggle language between C++, Python, and Java.
  - [ ] Click **Run Code** to execute sample test cases.
  - [ ] Click **Submit** to run full hidden test suite.
  - [ ] Verify "Accepted ✓" status and detailed execution metrics (time & memory).

---

## 6. Real Gemini AI Tutor Chatbot
- [ ] **Open AI Panel**:
  - [ ] Click floating circular AI Tutor button in the bottom right corner.
- [ ] **Ask Real Question**:
  - [ ] Type a question like "Explain Binary Search Trees with Python code".
  - [ ] Verify streaming thought indicator ("EduPath AI is thinking...") and real response generated by Gemini.
  - [ ] Test code copy button inside AI response markdown.
- [ ] **Chat Session History**:
  - [ ] Click the **History** icon in AI panel header.
  - [ ] Click **New Chat** to create a separate session.
  - [ ] Verify history loading from Supabase DB `chat_sessions` and `chat_messages`.

---

## 7. AI Progress Analysis & Recommendations
- [ ] Navigate to `/progress`.
- [ ] Verify Overall Performance metrics (Overall Progress %, Quiz Average %, Coding Accuracy %, Learning Streak, Study Time).
- [ ] Inspect Subject Analysis cards displaying Strong & Weak topics.
- [ ] Verify Rule/ML-based AI Insights & Recommendations tailored to your activity.

---

## 8. Gamification & XP System
- [ ] Navigate to `/achievements`.
- [ ] Check XP total, Current Level, and XP progress bar.
- [ ] Verify unlocked badges (e.g. "First Step", "Quiz Master", "Coding Master").
- [ ] View Weekly Leaderboard showing student rankings.

---

## 9. Subject & Semester Completion Certificates
- [ ] Complete all topics in a subject.
- [ ] Verify animated "🎉 Subject Completed!" screen, AI performance report, and **Download Certificate** button.
- [ ] Open printable PDF certificate popup.

---

## 10. Multi-User Data Isolation (RLS Verification)
- [ ] Create User A (`userA@test.com`) and complete 2 topics.
- [ ] Log out and create User B (`userB@test.com`).
- [ ] Verify User B has 0% progress and does not see User A's quiz/coding submissions or chat history.
